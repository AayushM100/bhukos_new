# Bhukos Frontend

React + TypeScript + Vite + Tailwind CSS frontend for Bhukos.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

The app will be available at `http://localhost:5173`

## Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run typecheck` - Run TypeScript type checking

## Stitch Design System

The frontend follows the Stitch Design System documented in `docs/ui/design.md`:

- Colors: `#FFF8F5` (surface), `#78350F` (primary), etc.
- Fonts: Newsreader, Plus Jakarta Sans, JetBrains Mono
- Layout: Editorial Letterboxd-inspired design
- No generic AI aesthetics - tactile print & archival quality
