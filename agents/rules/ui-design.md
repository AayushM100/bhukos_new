# UI & Design Rules — Bhukos

- **Primary Authority:** `docs/ui/design.md` (Stitch Design System) dictates all color tokens, fonts, spacing, borders, and surface contrast. Never override or ignore `docs/ui/design.md`.
- **Editorial Inspiration (Letterboxd-like, not an exact clone):**
  - Clean, spread-out, breathable layout with clear typographic hierarchy.
  - Use Bhukos domain labels: **Lists**, **Facts** (for daily food history), **Friends** (not "Members"), **Wishlist**, **My Collection**, and **Log**.
- **Strictly NO Generic AI Aesthetics:**
  - NO glowing neon borders, purple/indigo SaaS gradients, glassmorphism clutter, or repetitive plain rectangular boxes everywhere.
  - Keep surfaces mature, professional, highly readable, and restrained.
- **Collectible Card Design:**
  - Card visuals (`<FoodCard />`) should feel tactile and collectible (artwork, flavor pills, average rating, fun quote, subtle rarity indicator) while still harmonizing with the editorial page around them.
- Verify responsiveness across desktop and mobile viewports.
